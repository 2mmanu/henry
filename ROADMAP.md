# Roadmap

## 0.1 — Governed execution slice

- Stabilize task, capability, context and result contracts.
- Exercise real OmniAgent session execution through the adapter.
- Document the runtime adapter conformance contract.

## 0.2 — Durable governance plane

- Add PostgreSQL repositories and migrations.
- Add OIDC/workload identity and tenant isolation.
- Persist immutable audit records and distributed traces.
- Externalize policy bundles and approval workflows.

## 0.3 — Multi-domain orchestration

- Implement facilitator planning and task decomposition.
- Add domain registration, mediator exchanges and scoped delegation.
- Add digital-twin memory boundaries and retention policies.
- Publish conformance and adversarial context-leakage suites.
- Publish a provider-adapter specification and validate a second non-demo runtime.

## 1.0 — Production baseline

- Define compatibility guarantees and versioned contracts.
- Complete threat model, operational runbooks and independent security review.
- Demonstrate multi-instance reliability and disaster recovery.
